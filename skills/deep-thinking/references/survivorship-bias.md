# 幸存者偏差：检查未被看见的样本

## 定义

幸存者偏差是一种选择偏差：只分析经过筛选后留下的样本，忽略失败、退出或淘汰者，从而对整体作出失真的判断。

## 经典研究案例：Wald 分析返航飞机的损伤

**问题：只能观察返航飞机的命中情况，怎样估计参战飞机被击落的风险？**

Wald 的战时备忘录由 CNA 于 1980 年重印。第一部分明确列出可观察数据与需要估计的未知量。[来源：Wald，A Method of Estimating Plane Vulnerability Based on Damage of Survivors，Part I，印刷页 1–2](https://www.cna.org/reports/1980/0204320000.pdf)

| 分析要素 | 原报告中的设定 |
| --- | --- |
| 目标总体 | 所有参加战斗的飞机。 |
| 已知数据 | 参战总数 `N`，以及受到恰好 `i` 次命中且仍返航的飞机数 `Aᵢ`。 |
| 样本筛选 | 能记录损伤的飞机必须先存活返航，被击落的飞机没有进入这份损伤样本。 |
| 需要估计 | 遭受若干次命中后的被击落概率，以及此前存活条件下下一次命中的致命概率。 |
| 分析处理 | 在明确模型假设后，建立返航命中分布与未知击落概率的关系，而不是直接把返航比例当成全体概率。 |

**结论：**返航飞机提供的是经过生存条件筛选的数据。报告研究的是如何从这类不完整观测推断脆弱性，不能把幸存者的损伤分布直接视为全部参战飞机的损伤分布。

## 经典实证案例：补回消失基金后，业绩评价怎样改变

**问题：只研究期末仍存续的基金，会把历史业绩高估多少？**

Elton、Gruber 和 Blake 追踪期初基金，并把并购消失者纳入评价。以下采用论文 Table 2、Panel A 上半部分的三指数风险调整口径，数值取自紧随表格的解释段。[来源：Survivorship Bias and Mutual Fund Performance，1996，印刷页 1105–1107](https://pages.stern.nyu.edu/~eelton/papers/96.pdf)

| 分析环节 | 研究中的具体处理与结果 |
| --- | --- |
| 确定原始总体 | 从 1976 年末的普通股票基金样本出发，而不是从期末仍存在的名单倒查。 |
| 找回遗漏对象 | 保留后来被并购的基金；该口径计算其截至并购当月的收益，并计入并购条款。 |
| 比较同一指标 | 仍存续基金的平均年化 α 为 −0.1269%；包含消失基金的整体为 −1.0338%。α 是三指数模型下的风险调整业绩，不是原始收益率。 |
| 量化选择偏差 | 以“存续者平均 α − 全样本平均 α”计算，`−0.1269 − (−1.0338) = 0.9069`，即年化偏差约为 0.91 个百分点。 |

**修正后的判断：**只保留存续基金，会把平均风险调整业绩描述得更好。补回消失者后，估计下降；这里改变结论的是样本选择，而不是基金历史收益发生了变化。
