# 六顶思考帽：切换分析视角

## 定义与视角

六顶思考帽通过切换事实、感受、风险、价值、创造和过程组织六种视角，帮助全面审视问题并减少不同讨论目标的混杂。

围绕同一个问题，分别使用以下视角，避免将事实、感受和判断混在一起。

| 思考帽 | 关注点 | 核心提问 |
| --- | --- | --- |
| 白帽 | 事实与信息 | 已知事实和证据是什么？还缺哪些信息？ |
| 红帽 | 感受与直觉 | 有哪些直觉、偏好或担忧？ |
| 黑帽 | 风险与限制 | 哪里可能失败？成立条件有哪些？风险依据是什么？ |
| 黄帽 | 价值与机会 | 有什么收益？在什么条件下可行？ |
| 绿帽 | 创意与替代 | 还有哪些办法？能否改变假设或组合已有方案？ |
| 蓝帽 | 目标与组织 | 当前要解决什么？接下来分析什么？如何收敛结论与下一步？ |

红帽允许表达无需论证的感受，但不能把感受当作事实证据；未获得用户或参与者的感受时，不代为编造。黑帽指出具体风险及其依据，黄帽说明收益成立的条件，绿帽提出的想法仍需验证。

帽子代表视角，不代表六个人格；团队讨论时，成员同时使用同一顶帽子，再共同切换。[来源：Edward de Bono Ltd，The Six Thinking Hats](https://www.debono.com/_files/ugd/acf405_0ec0d7f959d7424fad5a9f9e9ec581e7.pdf)

## 公开实践案例：麦当劳日本改善会议

**问题：如何改善跨部门协作、会议效率与创造性讨论？**

De Bono Group 发布的 2000 年案例报告记录了麦当劳日本的培训与应用，以下为报告内容摘要。[来源：De Bono Group，McDonald’s Japan，Victoria Carver，2000](https://legacy.debonogroup.com/roi_mcDonalds.php)

| 环节 | 来源记载的实践与结果 |
| --- | --- |
| 面临问题 | 企业需要应对业务变化、加强跨部门协作并提高总部生产率。 |
| 引入方法 | 1999 年在人力资源部门试点；2000 年从董事会培训开始推广，团队共同参训，并在培训中讨论真实工作问题。 |
| 改变讨论 | 让成员参与不同类型的思考，减少黑帽思考占比，避免讨论长期停留在否定与风险上。 |
| 跟进应用 | 提供提示卡等工作辅助材料，并通过访谈、观察及培训后三个月的问卷跟进。 |
| 报告结果 | 员工报告会议时间减少约 25%，沟通更开放，工作氛围更积极。 |

这是培训机构发布的客户实践报告；原文没有给出某次会议六顶帽子的逐项发言或结论，不能据此补写。报告中的效率变化也不等同于受控实验得出的因果效果。

## 官方教学案例：评估一站式诊所

**问题：是否将多项诊断检查集中到一次就诊中完成？**

NHS《Sustainability Guide》给出了以下六顶帽子讨论示例。这是指南编写的教学情景，不是某次会议的实录。[来源：NHS，2010，印刷页 42](https://www.england.nhs.uk/improvement-hub/wp-content/uploads/sites/44/2017/11/NHS-Sustainability-Guide-2010.pdf)

| 思考帽 | 原案例中的分析内容摘要 |
| --- | --- |
| 绿帽：提出想法 | 在尚未采用这一方式的服务领域，设置一站式诊所。 |
| 黄帽：识别价值 | 患者只需到院一次，可更快诊断，并获得协调、整合的服务。 |
| 黑帽：检查风险 | 严重诊断可能来得过快，患者难以承受；集中多位专业人员也可能影响其他服务。 |
| 白帽：明确缺口 | 需要了解告知坏消息的规范、服务容量与需求，以及患者意见。 |
| 红帽：表达感受 | 直觉上认为能更好地服务患者，同时担心变化对工作人员的影响。 |
| 蓝帽：组织后续 | 调查患者意见，与患者共同完善告知坏消息的材料；小规模试行，四周后复查。 |

**示例总结：**示例分别呈现了方案创意、预期收益、风险、信息需求和感受；蓝帽提出调查患者意见、完善沟通材料、小规模试行并在四周后复查的后续安排。原文未报告这些安排的实施结果。
