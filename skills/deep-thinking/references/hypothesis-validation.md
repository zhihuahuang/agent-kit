# 假设—验证：让判断可检验

## 定义

假设—验证是提出可检验的解释，再用证据检验并修正它的分析方式，既检查支持证据，也寻找反例与适用边界。

## 经典研究案例：幽门螺杆菌与胃部疾病

**问题：胃内细菌是无害伴生物，还是胃部炎症的原因？**

Marshall 在诺贝尔奖自传与演讲中回顾了这一研究。以下区分观察、感染实验与后续治疗验证。[来源：Marshall，自传](https://www.nobelprize.org/prizes/medicine/2005/marshall/biographical/)、[诺贝尔演讲](https://www.nobelprize.org/uploads/2018/06/marshall-lecture.pdf)

| 研究环节 | 已有证据与判断 |
| --- | --- |
| 观察与假设 | Warren 在胃活检中观察到细菌与炎症的联系；研究者提出细菌可能致病，而非仅仅伴随病变存在。 |
| 检验因果解释 | Marshall 的自我感染实验出现细菌定植和胃黏膜组织损伤，为感染能够引起胃炎提供证据。 |
| 扩展验证 | 研究者继续观察根除细菌后的治疗结果，并开展前瞻性双盲试验，检验抗菌治疗与十二指肠溃疡的关系。 |
| 修正判断范围 | 感染实验支持的是胃炎致病性；溃疡治疗与复发需要另外的临床证据，不能由一次实验直接推到所有胃溃疡。 |

**结论：**观察到共同出现只是起点；感染与治疗研究分别检验了因果链的不同环节。上述自我感染是历史事件，不是可供复现的实验建议。
