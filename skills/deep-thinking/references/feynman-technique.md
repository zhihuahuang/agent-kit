# 费曼方法：用解释检查理解

## 定义

费曼方法通过用清楚、简单的语言解释概念，暴露理解缺口，再补足并改进解释。

## 原著教学案例：费曼解释水的原子结构

**问题：看起来连续、平滑的水，如何用原子模型解释？**

《费曼物理学讲义》第一卷第 1 章从一滴水逐级放大，说明原子观念。这是费曼本人公开的教学实例，并非他执行现代“四步费曼学习法”的完整记录。[来源：Caltech，Atoms in Motion，§1–2、图 1–1](https://www.feynmanlectures.caltech.edu/I_01.html)

1. **从熟悉对象进入：**先观察一滴水；通过逐级放大的设想，从连续外观引出分子尺度。
2. **用具体结构解释：**图中每个水分子由一个氧原子和两个氢原子组成；分子不断运动，彼此吸引，距离过近时又相斥。
3. **连接可见现象：**分子吸引解释水为何不会自行散开；温度升高对应运动加强，足够强时分子可以分离成为水蒸气。
4. **指出简化之处：**图是二维、静态且边界清晰的，实际粒子却在三维空间持续运动，图中的轮廓也不是精确实物外形。

**解释结果：**原子模型被连接到水的整体行为，同时明确了示意图不能表达的内容。

## 原始教学案例：修正“能量让玩具狗运动”的解释

**问题：上紧发条的玩具狗为什么会动？**

费曼在 1966 年《What Is Science?》演讲中评议了一本教材的回答，并给出更具体的解释。这段材料展示的是识别解释缺口与修正解释，不是现代四步学习法的实验记录。[来源：费曼演讲，后刊于 The Physics Teacher，1969](https://feynman.com/science/what-is-science/)

| 环节 | 演讲中的具体分析 |
| --- | --- |
| 检查原解释 | 教材用“能量使它运动”作答，却没有说明玩具内部发生了什么。 |
| 发现理解缺口 | 费曼提出一个检验：不用刚学到的“能量”一词，以自己的语言说明玩具狗为什么运动。如果无法说明，就只是学会了名称，尚未理解运动机制。 |
| 补足具体机制 | 他建议拆开玩具观察结构，辨认发条、齿轮和棘轮怎样工作。 |
| 改写解释 | 发条被上紧后趋于松开，并推动齿轮转动；这比只说“有能量”提供了具体的因果连接。 |

**解释的变化：**从抽象术语转为可观察的部件及其作用关系。这里的缺口可以明确指出，修正后的说明也可以通过观察玩具结构检查。
