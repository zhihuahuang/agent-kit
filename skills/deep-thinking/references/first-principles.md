# 第一性原理：追到基本事实

## 定义

第一性原理从基本事实和必要约束出发推导解释或方案，用于识别未经检验的假设与惯例。

## 教科书案例：从光速不变推导时间膨胀

**问题：同一次光脉冲往返，飞船内外的观察者测得的时间是否相同？**

OpenStax《University Physics Volume 3》§5.3 用光钟给出完整推导。这是从基本假设推导结果的教材实例。[来源：OpenStax，Time Dilation，图 5.4、式 5.1](https://openstax.org/books/university-physics-volume-3/pages/5-3-time-dilation)

1. **基本前提：**两个观察者所在的惯性参考系相对匀速运动，均测得真空光速为 `c`。
2. **建立关系：**飞船内的光垂直往返，单程距离为 `D`，故固有时间 `Δτ = 2D/c`。外部观察者看到飞船同时横移，光走斜线。
3. **从前提推导：**由勾股定理，`(cΔt/2)² = D² + (vΔt/2)²`；代入 `D = cΔτ/2`，得到 `Δt = Δτ / √(1 − v²/c²)`。
4. **结论：**相对速度非零时，外部观察者测得的往返时间更长。结果来自光速不变和路径几何关系，而非预先假定所有观察者共享同一个时间。
