# SWOT 分析法：从条件形成策略

## 定义与维度

SWOT 从内部优势、内部劣势、外部机会和外部威胁四个维度评估对象，并据此形成策略。

| 维度 | 关注点 | 核心提问 |
| --- | --- | --- |
| S · Strengths | 内部优势 | 有哪些有利的能力、资源或积累？ |
| W · Weaknesses | 内部劣势 | 有哪些能力缺口、资源限制或短板？ |
| O · Opportunities | 外部机会 | 外部有哪些可以利用的有利变化？ |
| T · Threats | 外部威胁 | 外部有哪些可能阻碍目标的变化或压力？ |

从相关因素的组合提出策略，不停留在清单：利用优势抓住机会（SO）、借助机会弥补劣势（WO）、发挥优势应对威胁（ST）、减少劣势并降低威胁暴露（WT）。只展开有实际关联的组合，说明具体行动、成立条件及优先级依据。

## 大学公开案例：芝加哥社区发展项目

**问题：社区组织如何结合自身条件和外部机会，确定发展方向？**

堪萨斯大学 Community Tool Box 的 Example 1 记录了一个芝加哥社区组织的 SWOT。原案例将优势与机会合为积极因素，将局限与挑战合为消极因素。[来源：Community Tool Box，SWOT Examples，Example 1](https://ctb.ku.edu/en/table-of-contents/assessment/assessing-community-needs-and-resources/swot-analysis/example)

| 分析环节 | 案例中的具体内容 |
| --- | --- |
| 积极因素 | 伙伴信任、参与者投入、社区发展经验，以及内部和外部投资者的关注。 |
| 消极因素 | 人手不足、服务交付与倡导难以平衡、社区尚需明确成功标准，以及不利于社区的区域规划。 |
| 内外条件结合 | 资助者的关注带来争取项目资金的机会，但社区对成功的定义尚不清楚。 |
| 形成规划判断 | 项目选择应符合社区认定的重要目标；如果为了资金接受社区并不重视的项目，可能损害组织未来的成效。 |

**结论：**获得资金的机会需要与社区目标一起评估。原案例既辨认有利条件，也用内部问题约束机会选择，没有把“能拿到资助”直接等同于“应该开展项目”。

## 教材案例：Campbell Soup 的因素组合与策略

**问题：如何把四类因素转成具体的业务策略？**

堪萨斯大学 Community Tool Box 转引 Fred David《Strategic Management》的 Campbell Soup 历史案例，并保留因素编号与策略的对应关系。以下摘取其中部分内容，不代表企业当前情况或已经执行的决策。[来源：Community Tool Box，TOWS 矩阵示例](https://ctb.ku.edu/en/table-of-contents/assessment/assessing-community-needs-and-resources/swot-analysis/main)

| 维度 | 原案例中的因素 |
| --- | --- |
| S：内部优势 | 利润比率提高（S1）、员工士气高（S2）、市场份额增加（S3）。 |
| W：内部劣势 | 诉讼尚未解决、工厂产能下降、缺少战略管理系统。 |
| O：外部机会 | 西欧一体化（O1）、选购食品时健康意识上升（O2）、汤品需求逐年增加。 |
| T：外部威胁 | 美元价值低、罐头容器不可生物降解（T2）。 |

原矩阵明确给出的部分策略连接是：

- **S1、S3 与 O1：**把财务及市场优势与欧洲机会结合，提出收购欧洲食品企业。
- **S2 与 O2：**把员工优势与健康需求结合，提出开发新的健康汤品。
- **S1 与 T2：**把财务优势用于应对包装问题，提出开发可生物降解的汤品容器。

**分析产出：**每项策略都标明它连接了哪些内部条件与外部变化，形成了可追溯的策略候选，而不只是四份因素清单。
