# 奥卡姆剃刀：减少不必要的假设

## 定义

多个解释同样符合现有证据时，优先考虑额外假设更少的解释。

## 官方教材案例：NIST 的热电偶校准模型

**问题：热电偶的温度与输出电压应使用多复杂的模型拟合？**

NIST 手册先提出从能描述数据的简单函数开始，再用残差检验；热电偶校准给出了简单模型被证据否定的具体例子。[来源：NIST，模型选择](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd422.htm)、[模型充分性检验](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd441.htm)

| 比较环节 | 案例中的判断 |
| --- | --- |
| 初始候选 | 数据呈现曲率，二次模型是合理的简单起点。 |
| 检查简单模型 | 拟合后残差随温度呈明显周期结构，说明二次模型遗漏了规律。 |
| 比较较复杂模型 | LOESS 拟合的残差没有明显系统结构；二次模型的残差范围约为它的 50 倍。 |
| 根据证据修正 | 二次模型虽然简单，却不足以解释数据，不能因其简单而继续采用。 |

**结论：**简单性是满足解释要求后的选择原则。该例中，增加复杂度有残差证据支持，不属于无必要地增加假设。[NIST 对奥卡姆剃刀的说明](https://www.itl.nist.gov/div898/handbook/apr/section2/apr24.htm)

## 官方教材案例：删去没有充分证据支持的模型项

**问题：描述晶圆沉积层应力，是否需要完整二次模型中的所有项？**

NIST 的响应面案例取自《Statistical Case Studies for Industrial Process Improvement》，比较压力 `P` 与反应气体比例 `R = H₂/WF₆` 对应力的影响。[来源：NIST，§5.4.7.3，Stress 模型分析](https://www.itl.nist.gov/div898/handbook/pri/section4/pri473.htm)

| 比较环节 | 原案例的处理与证据 |
| --- | --- |
| 完整候选 | 包含截距、`P`、`R`、`P²`、`P×R`、`R²`。 |
| 简化候选 | 保留截距、`P`、`R`、`P²`，去掉交互项与气体比例平方项。 |
| 判断额外复杂度 | 两个模型的比较检验给出 `p = 0.22`；交互图也没有显示明显交互，未发现保留额外两项的充分依据。 |
| 检查简化结果 | 简化模型的失拟检验 `p = 0.73`，未检出明显失拟；原案例据此继续使用简化模型。 |

**结论：**在当前数据支持下保留较少的项，而不是因为项更多就认为解释更好。未检出显著差异不等于证明模型完全等价；这个案例展示的是有证据约束的简化选择。它与前面的热电偶案例互补：一个删去不必要复杂度，一个保留必要复杂度。
