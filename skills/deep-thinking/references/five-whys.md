# 5 Whys：逐层追因

## 定义

5 Whys 通过连续追问原因，从现象深入到背后的因果机制。“五次”不是固定次数。

## 经典教学案例：大野耐一的机器停机

**问题：机器为什么停止工作？**

Lean Enterprise Institute 引述大野耐一《丰田生产方式》（1988 年英文版，第 17 页）的示例，给出以下追问链。[来源：LEI，5 Whys](https://www.lean.org/lexicon-terms/5-whys/)

| 追问 | 案例中的回答 |
| --- | --- |
| 为什么机器停机？ | 发生过载，保险丝熔断。 |
| 为什么过载？ | 轴承没有得到充分润滑。 |
| 为什么润滑不足？ | 润滑泵供油不足。 |
| 为什么泵供油不足？ | 泵轴磨损、松动。 |
| 为什么泵轴磨损？ | 没有安装滤网，金属碎屑进入。 |

**结论：**调查从保险丝熔断追到碎屑进入的机制。只更换保险丝或泵没有消除这一原因，故障仍可能复发；追问的目的在于找到并消除根因，而不是凑满五次。
