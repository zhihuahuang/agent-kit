# 深度思考

对观点、被当作事实的说法、意见、想法、技术、知识、讨论、交流、数据等，逐项运用思考方法、悖论与偏差视角，深入分析、解释和论证，澄清含义、检查前提与依据、发现关联并修正判断。

## 思考过程

1. 结合用户输入与上下文，明确需要思考的目标对象及需要回答的问题；目标对象可能是一个问题、观点、知识、数据等。如果目标对象不明确或存在歧义，则要求用户澄清。
2. 针对目标对象，逐个应用思考方法。必须读取索引中每个方法的参考文件，依据其中的定义、维度及案例展示的分析方式，按照对应的思考模式实际分析目标对象。悖论与偏差也须检查其成立条件及对当前判断的影响。不得遗漏任何方法，不得仅凭方法名称或适用线索预判不相关而跳过。
3. 逐项输出每个方法的分析摘要，使后续分析能够辨认各方法的结果：

   - 得出结论：说明该方法检查了什么、关键依据是什么、得出了什么结论，以及对目标问题的回答有何影响；依赖假设的结论须标明假设。
   - 不适用：说明尝试如何将该方法用于目标对象，以及哪个必要条件不成立；不能只写“不相关”或“不适用”。
   - 信息不足：说明已能确定的内容、缺少的关键信息及因此无法确定的问题；不得编造结论，也不得将信息不足归为不适用。
   - 即使不同方法得到相同结论，也必须分别说明各自的分析依据与结论。输出前对照索引检查，确保每个方法都有明确结果。
4. 将分析中影响结论且尚未解决的关键假设、依赖或新问题作为新的目标对象重新执行上述过程，并据此修正原结论。已有分析可以复用，避免重复展开；当进一步分析不再实质影响对目标问题的回答，或受限于当前无法获得的关键证据时，停止展开，说明尚未解决的问题及其影响。最后综合各方法的结果回答目标问题；结论存在冲突时，必须检查各结论的前提、证据、推理与适用条件，针对冲突重新验证，修正不成立的判断并更新综合结论；仍无法消解时，说明剩余分歧、依据及所需证据，不得强行统一结论。

## 思考方法索引

“思考方法”统称下列方法、悖论与偏差视角；“思考模式”指各条目所要求的分析角度与动作。每个条目都必须实际尝试并记录结果。

| 方法与参考 | 简短定义 | 适用线索 |
| --- | --- | --- |
| [5W2H](references/5w2h.md) | 从对象、主体、时间、位置、原因、方式及数量成本七个维度理解问题 | 需要厘清概念、场景、角色、机制或成本时 |
| [5 Whys](references/five-whys.md) | 逐层追查原因，深入解释机制 | 需要追查现象、行为或决定背后的原因时 |
| [假设—验证](references/hypothesis-validation.md) | 检验判断的依据、反例与适用边界 | 检查关键判断及其成立条件；有待验证假设时设计验证 |
| [第一性原理](references/first-principles.md) | 从基本事实与约束解释机制 | 需要从基本事实解释机制，或现有解释停留在惯例与表象时 |
| [系统思维](references/systems-thinking.md) | 理解关联、反馈和连带影响 | 涉及多个主体、因素、环节及其相互影响时 |
| [六顶思考帽](references/six-thinking-hats.md) | 分开审视事实、感受、风险、价值与创意，并组织结论 | 方案评估、多角度分析或团队讨论时 |
| [奥卡姆剃刀](references/occams-razor.md) | 在解释力相当时优先选择额外假设更少的解释 | 筛选原因、选择模型或检查过度设计时 |
| [贝叶斯思维](references/bayesian-thinking.md) | 根据新证据更新判断，比较不同解释的可信程度 | 存在不确定性、多个候选原因或持续出现新证据时 |
| [逆向思维](references/inversion.md) | 从失败条件或相反目标发现遗漏与防护需求 | 方案设计、风险排查或正向分析陷入僵局时 |
| [SWOT 分析法](references/swot.md) | 分析内部优势、劣势与外部机会、威胁，形成策略 | 战略规划、方案评估或资源投入决策时 |
| [费曼方法](references/feynman-technique.md) | 用清楚的解释暴露理解缺口，再补足并改进解释 | 学习、教学或概念难以讲清时 |
| [辛普森悖论](references/simpsons-paradox.md) | 各分组趋势一致，汇总后却可能反转的统计现象 | 比较总体与分组的比例、趋势或关联时 |
| [幸存者偏差](references/survivorship-bias.md) | 只观察筛选后留存的样本，忽略失败或退出者而产生偏差 | 根据留存案例、可见群体或筛选后的数据作判断时 |
